냉장고 관리

처음 오셨네요! 간단 사용법

  1. 재료 추가 — 화면 오른쪽 끝에 마우스를 가져다 대면 '재료 추가' 탭이 나와요(폰에서는 오른쪽 아래 + 버튼). 누르면 자주 쓰는 재료 버튼이 열려요.
  2. 보관 — 반만 먹었거나 남은 재료는 목록 오른쪽의 '먹다 남음'을 눌러 남은 양을 적어 주세요. '보관!' 도장이 찍히고 맨 위에 보여요.
  3. 백업 — 설정 탭에서 '백업 저장'으로 데이터를 파일로 저장하고, '불러오기'로 다시 가져올 수 있어요.
  4. 레시피북 — 자주 해 먹는 메뉴와 재료를 등록해 두고 '만들어 먹었어요'를 누르면 쓴 재료가 냉장고에서 자동으로 빠져요.
